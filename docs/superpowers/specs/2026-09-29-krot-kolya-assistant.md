# Крот Коля: локальный помощник

Крот Коля закреплён в правом нижнем углу сайта и по умолчанию стоит и моргает. По клику открывается компактный чат без ИИ и без серверной части: ответ выбирается из локальной базы знаний по ключевым словам с учётом текущего раздела.

Состояния питомца: `idle`, `wave`, `tablet`, `jump`, `waiting`, `failed`, `review`. Открытие чата вызывает `wave`, отправка вопроса — `tablet`, найденный ответ — `review`, отсутствие ответа — `failed`; после короткой реакции питомец возвращается в `idle`. Переход между страницами вызывает короткий `jump`.

Интерфейс должен быть доступен с клавиатуры, не перекрывать основной контент на мобильном экране и не добавлять внешние зависимости.
