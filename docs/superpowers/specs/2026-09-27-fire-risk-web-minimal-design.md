# Fire Risk WEB — Minimal Design

## Цель

Быстро собрать цельный русскоязычный desktop-интерфейс для демонстрации сценария пожарного риска, используя существующий API и явно обозначенные demo-данные там, где API пока не отдаёт нужные поля.

## Объём

Один React + TypeScript + Vite SPA в `services/web` с маршрутами:

1. Dashboard.
2. Объекты и линейная SVG-карта пикетов.
3. Журнал и полная карточка предупреждения.
4. Заявки.
5. Аналитика.
6. Журнал SMS.

## Архитектура

- `api.ts` содержит fetch-клиент и переключение на demo-fixture при `VITE_DEMO_MODE=true`.
- `types.ts` фиксирует ответы существующих API endpoints.
- Общий shell и небольшие переиспользуемые компоненты обеспечивают единый вид.
- Простые SVG-компоненты строят линейную карту и динамику вероятностей без chart-библиотеки.
- Demo-поля помечаются как «Демонстрационные данные» и не смешиваются с фактическими значениями API.

## Ключевые правила

- Технический сбой отображается отдельным типом, не как пожар.
- Возраст датчика числовой; источник оценки видим рядом или в подсказке.
- Карта сохраняет отдельную группу каналов без пикета и подсвечивает опасный диапазон.
- Карточка предупреждения включает уровень, горизонт, адресатов, время, объект, пикет, вероятность, ID, датчики, ТО, динамику, контекст, факторы, рекомендации, историю, решения, заявку и SMS.
- Аналитика прямо сообщает, что метрики рассчитаны на proxy/demo-разметке.
- Цвет риска всегда дублируется текстом.

## Проверка

- Небольшие unit/component-тесты только для критичных правил: подписи уровней, технический сбой и каналы без пикета.
- Одна итоговая проверка `test`, `typecheck` и `build`.
- Полный Playwright E2E и отдельные коммиты WEB-01…WEB-06 исключены ради скорости.
